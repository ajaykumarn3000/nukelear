About

Intelligent project cleanup for developers

What is Nukelear?

Nukelear is a powerful developer utility that helps you reclaim disk space by identifying and cleaning unnecessary build artifacts, dependencies, and development clutter. Available as both a CLI tool and a standalone web application, Nukelear provides a safe, efficient way to manage project storage without risking important files.

With support for Node.js, Next.js, Python, VS Code, and macOS-specific files, Nukelear detects known clutter patterns and gives you full control over what gets cleaned. The recycle bin system allows you to restore items if needed, and file content preview lets you inspect files before deletion.

The Problem

Modern development projects accumulate significant amounts of generated files and dependencies over time. A single project can contain gigabytes of `node_modules`, build artifacts, cache directories, and editor-specific files. When managing multiple projects across nested directory structures, this clutter consumes disk space unnecessarily and makes it difficult to identify what can be safely removed.

Manually tracking and deleting these directories is tedious, error-prone, and risky. Developers often leave clutter sitting around for months or years, wasting storage and creating backup bloat.
