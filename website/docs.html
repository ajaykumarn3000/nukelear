Getting Started

Nukelear is available as both a standalone web application and a CLI tool. The web application requires a browser that supports the File System Access API (Chrome, Edge, Brave, or Opera on desktop).

Web Application

Open nukelear-web.html in your browser. No installation required.

CLI Installation

# Install globally
npm install -g nukelear

# Or use npx without installation
npx nukelear@latest <directory>

System Requirements

  • Node.js 18.0 or higher
  • npm 7.0 or higher (or yarn/pnpm equivalent)

Web Application

The web application provides a complete graphical interface for project cleanup with recycle bin support and file content preview.

Select Project

Click "Choose Folder" and select the project directory you want to clean. Grant browser access to the folder when prompted. The project size will be displayed immediately.

Select Technologies

Choose which technologies to scan for. Available options include Node.js, Next.js, Python, VS Code, and macOS. The scan runs automatically when you change your selection.

Scan

Nukelear recursively scans the project for directories matching the selected technology patterns. Detected items are displayed with their paths and sizes.

Review Results

Review the detected items before cleanup. You can see the total reclaimable size and individual item sizes. Use "Select All" or "Clear Selection" to manage your choices quickly.

Preview Files

Click the View icon (👁️) next to any item to preview its contents. For directories, you can see contained files. For files, you can read actual text/code content safely before deletion.

Select Items

Check the items you want to clean. You can select individual items or use bulk selection controls. The selected size is displayed in real-time.

Move to Recycle Bin

Click "Move to Recycle Bin" to clean selected items. Type "delete" in the confirmation dialog to proceed. Items are moved to a local .nukelear-trash directory within your project.

File Preview

Nukelear allows you to inspect actual file contents before cleanup, helping you avoid accidental deletion of important files.

Directory Preview

When previewing a directory, you can see all contained files and folders. Each child item can be clicked to open its own preview.

File Content Preview

For readable text files (JavaScript, TypeScript, JSON, HTML, CSS, Python, Markdown, etc.), Nukelear displays the actual file contents in a scrollable preview window. Binary files are clearly marked as unsupported.

Note: File preview is read-only. No files are modified during preview operations.

Size Limits

Large text files are truncated at 10,000 characters with a clear indication. Files larger than 100KB are not loaded into the preview to maintain performance.

Cleanup

Cleanup operations move selected items to the recycle bin rather than permanent deletion by default.

Type-to-Confirm

Before any cleanup operation, you must type "delete" to confirm. This prevents accidental deletion of important files.

Size Calculation

Project size is calculated recursively, excluding .git and .nukelear-trash directories. This ensures that recycle bin contents do not affect project size calculations.

Result Display

After cleanup, you can see the project size before, the amount freed, and the project size after the operation.

Recycle Bin

All cleaned items are stored in a local recycle bin located at .nukelear-trash within your project directory.

View Recycle Bin

Open the "Recycle Bin" tab in the web application to see all items currently stored. Each entry shows the original path, size, and timestamp.

Empty Recycle Bin

Click "Empty Recycle Bin" to permanently delete all items. This operation requires type-to-confirm ("delete") and cannot be undone.

Warning: Emptying the recycle bin permanently deletes all items. This action cannot be undone.

Restore

Items in the recycle bin can be restored to their original locations at any time.

Restore Items

In the Recycle Bin tab, click "Restore" next to any item to recover it. The item is moved back to its original path.

CLI Restore

# List items in recycle bin
nukelear <directory> --list-trash

# Restore a specific item by id
nukelear <directory> --restore <id>

CLI

The CLI provides fast terminal-based cleanup with interactive prompts and flags for automation.

Basic Usage

nukelear <directory> [options]

Interactive Mode

Run without flags to enter interactive mode. You'll be prompted to select technologies and directories.

nukelear ~/Dev

Technology Flags

# Clean only Node.js dependencies
nukelear ~/Dev --node

# Clean multiple technologies
nukelear ~/Dev --node --python

# Clean all supported technologies
nukelear ~/Dev --node --next --python --vscode --macos

Recycle Bin Commands

# List recycle bin contents
nukelear <directory> --list-trash

# Restore item by id
nukelear <directory> --restore <id>

# Empty recycle bin permanently
nukelear <directory> --empty-trash

Permanent Deletion

Use --permanent to delete items immediately without moving to the recycle bin.

nukelear ~/Dev --node --permanent
Warning: Permanent deletion cannot be undone. Use with caution.

Help and Version

nukelear --help
nukelear --version

Safety

Nukelear includes multiple safety mechanisms to prevent accidental data loss.

Recycle Bin Default

By default, items are moved to the recycle bin rather than permanently deleted. This allows recovery if needed.

Type-to-Confirm

Destructive operations require typing "delete" to confirm. This prevents accidental clicks from causing data loss.

File Preview

You can inspect file contents before cleanup to verify that items are safe to delete.

Size Exclusion

The .git and .nukelear-trash directories are excluded from size calculations and scanning to prevent accidental version control or recycle bin deletion.

Read-Only Preview

File preview operations are strictly read-only. No files are modified, executed, or uploaded during preview.

Best Practice: Always review detected items and preview important files before cleanup. Use the recycle bin as a safety net until you're confident items can be permanently deleted.
