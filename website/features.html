Features

Powerful tools for intelligent project cleanup

🔍

Intelligent Scanning

Recursive directory scanning identifies cleanup targets by technology type. Detects known patterns for Node.js, Next.js, Python, VS Code, and macOS.

📊

Size Analysis

Calculate exact sizes for detected directories and files. See total reclaimable space before making any cleanup decisions.

👁️

File Preview

Preview directory contents before cleanup. View file metadata including path, size, and type. Navigate nested directories easily.

📄

Content Preview

Read actual file contents safely. Preview text files, code, and configuration files before deletion. Binary files are clearly marked as unsupported.

🗑️

Safe Cleanup

Move items to a recycle bin instead of permanent deletion. Type-to-confirm prevents accidental cleanup. Review before confirming.

♻️

Recycle Bin

All cleaned items are stored in a local recycle bin. View contents, sizes, and original paths. Restore items when needed.

↩️

Restore

Recover individual items from the recycle bin. Items are restored to their original locations. Undo cleanup operations easily.

🎯

Technology Detection

Automatic detection of project technologies. Select specific technologies or scan for all supported types. Configurable via CLI flags.

🔐

Secret Detection

Detect potential secrets in files before GitHub upload. Common patterns are identified and can be redacted automatically.

📤

GitHub Integration

Upload cleaned projects directly to GitHub repositories. Create new repositories or push to existing ones. Secret-aware upload workflow.

💻

Cross-Platform

Works on macOS, Linux, and Windows. Available as both a CLI tool and a standalone web application with File System Access API.

⚡

Fast & Lightweight

Built with TypeScript for performance. No heavy dependencies. Fast scanning of large projects with minimal overhead.
